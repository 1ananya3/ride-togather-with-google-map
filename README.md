# ride-togather-with-google-map
Ride Together Mode is a proposed collaborative feature for Google Maps designed for group road trips involving multiple vehicles.

It allows riders to join a shared trip, view each other's live locations, see who is ahead or behind, share stop statuses, and receive real-time notifications when someone stops or gets separated.

The project is being built as a full-stack prototype using React, TypeScript, Node.js, Express, MySQL, Prisma, Redis, WebSockets, and Google Maps API.

Google Maps answers: “How do I get there?”
Ride Together Mode answers: “Where is everyone, and are we still together?”
